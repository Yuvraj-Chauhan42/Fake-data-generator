# Fake-data-generator
A Python CLI tool that generates synthetic data using Faker and exports it to Excel with Pandas.
## Features
- Generate fake names and email addresses
- Generate phone numbers and addresses
- Generate cities, companies, and job titles
- Choose from multiple regions
- Export data to Excel

## Technologies Used
- Python
- Faker
- Pandas
- openpyxl

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the program:

python main.py
